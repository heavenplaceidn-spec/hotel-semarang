# Hotel Semarang

WebGIS persebaran hotel, penginapan, dan tempat menarik di Kota Semarang.

Buka [`index.html`](index.html). Data titik, jalan, dan kelurahan sudah tertanam di berkas itu, jadi bisa dijalankan tanpa server. Perlu internet untuk gambar peta.

Peta **Jalan** memakai peta jalan Esri, bukan ubin OpenStreetMap. Ubin OSM menolak berkas yang dibuka langsung dari komputer.

Ini bukan repositori CASCADE.
